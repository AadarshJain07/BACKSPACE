# BACKSPACE 🌐

### The internet, through time.

BACKSPACE is an interactive web experience that lets you explore how the internet evolved across different eras.

Choose a year and watch the entire experience transform — from the visual design and typography to layouts, interactions, technology, and internet culture.

## 🚧 Status

**Day 1 / 30 — In Development**

This project is being built publicly over 30 days, with new features and improvements added every day.

## 🎯 Vision

BACKSPACE aims to make the history of the internet something you can **experience**, rather than simply read about.

Travel through:

`1995 → 2000 → 2005 → 2010 → 2015 → 2020 → 2026 → Future`

## 🛠️ Built With

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion

## 🚀 Development

```bash
npm install
npm run dev
```
